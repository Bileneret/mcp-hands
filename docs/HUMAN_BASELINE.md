# HUMAN BASELINE — чек-лист ручного хронометража (DESIGN §7)

Методика (согласована с аудитором, этап 5): время человека измеряется **вручную
владельцем** по шагам чек-листа — что именно считается «одной задачей» для агента.
Засекайте время честно: от первой операции до закрытия задачи, без ускорений
«спиной»; пользователь — квалифицированный (знает Word/Excel/браузер).

Заполните третий столбец в формате `мм:сс` (например `1:45`) — сводка этапа 5
(`mcp_hands/benchmark/report.py`) подхватит суммы автоматически и посчитает
коэффициент ускорения агента. Пустые ячейки = «ещё не замерялось».

| Задача | Шаги для замера (что делать руками) | Время, мм:сс |
|---|---|---|
| b01 | Word: открыть шаблон отчёта, заполнить реквизиты, проверить структуру, сохранить под новым именем | |
| b02 | Word: расставить заголовки стилями, шрифт, интервалы 1.5, вставить оглавление, сохранить | |
| b03 | Word: открыть документ, заполнить поля, экспорт в PDF, проверить PDF | |
| b04 | Браузер: открыть страницу источников, выписать 4 записи (автор/год/ссылка) в таблицу | |
| b05 | Браузер: скопировать текст статьи, вставить в Word, оформить цитату источника | |
| b06 | Браузер: открыть 4 вкладки, сгруппировать по доменам, сохранить список, закрыть лишние | |
| b07 | Медиа-страница: включить видео, поставить скорость 1.5x, выписать 4 таймкода в заметки | |
| b08 | Файлы: разложить 5 файлов по типовым папкам, лишний отправить в корзину | |
| b09 | Excel: свести два CSV в один лист, построить столбчатую диаграмму, сохранить | |
| b10 | Комбо: источники в CSV, статья в Word с цитатой, экспорт в PDF | |

**Ориентир объёма** (аудитор, v21): суммарно для квалифицированного пользователя
ожидается порядка **10–15 минут** (600–900 секунд) на все десять задач против
**~1 минуты** у агента. Эти цифры — плановые; таблица выше важнее: только ваш
замер попадает в публичные метрики.
